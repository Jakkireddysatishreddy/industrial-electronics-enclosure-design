# Industrial Electronics Enclosure Design

## Project Overview

This project focuses on the mechanical design of a compact industrial
electronics enclosure intended to protect and support an internal PCB.

The design considers mechanical strength, thermal management,
connector accessibility, manufacturability, and maintenance.

## Design Objectives

- Protect internal electronics
- Provide secure PCB mounting
- Allow easy maintenance
- Provide connector accessibility
- Improve heat dissipation
- Maintain manufacturability
- Reduce unnecessary material

## Design Specifications

| Parameter | Specification |
|---|---|
| PCB Size | 210 × 160 × 1.5 mm |
| Operating Temperature | -10 to 55 °C |
| Installation | Wall mounted |
| Approx. Device Mass | 2 kg |
| Manufacturing | CNC / 3D Printing |
| CAD Software | Autodesk Fusion 360 |
